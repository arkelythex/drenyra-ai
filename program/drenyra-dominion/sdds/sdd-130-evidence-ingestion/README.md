# SDD-130 — Evidence Ingestion and Provenance

> Status: lifecycle:planned · Wave: 5 · Depends on: SDD-120, SDD-110 · Feeds: SDD-140, SDD-150

## Capability boundary

Plan fail-closed capture and normalization of attributable ERP, SIRE, bank, document, and other fiscal inputs into canonical evidence references. Every accepted artifact remains tenant/RUC/period scoped, content-addressed, provenance-bearing, and reproducible.

## Required outcome

- Rejected or ambiguous input never becomes a partial authoritative evidence set.
- Adapter capability and source identity are explicit and revision-bound.
- Memory and model output never substitute for evidence.

## Non-claims

Catalog presence does not ship connectors, grant privileged external access, authorize fiscal action, or claim that ingestion is implemented.
